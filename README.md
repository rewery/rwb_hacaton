# Mesh-доставка с хранением в ПВЗ — прототип (RWB × ПГТУ)

Расчётная модель в Excel + сервер на Python (FastAPI) + веб-интерфейс с двумя режимами: **ПВЗ** и **Продавец**.

## Запуск одним файлом
- **Windows:** двойной клик по `START.bat`. Первый запуск сам создаёт `.venv` и ставит библиотеки (Python 3.9+, интернет), дальше стартует сразу и открывает http://127.0.0.1:8000.
- **macOS / Linux:** `./start.sh` или `python3 run.py`.
- **Docker:** `docker compose up --build` → http://localhost:8000.
- **Swagger:** `/api/docs`. **Тесты:** `pip install -r requirements-dev.txt && pytest`.

Если порт 8000 занят другой программой, лаунчер берёт ближайший свободный; если сайт уже запущен — просто открывает его.

## Структура
```
START.bat / start.sh   запуск в один клик
run.py                 лаунчер: .venv → pip install → uvicorn → браузер
config.json            порт и путь к Excel-книге
main.py                API (FastAPI) и раздача страниц
excel_io.py            чтение Excel-книги
engine.py              сквозной процесс: приёмка → заказ → рейс → выдача → возврат → начисления
static/                index.html, style.css, app.js — весь интерфейс
data/                  Mesh_проверка_модели.xlsx — единственная таблица
tests/                 pytest
```

## Одна таблица Excel
Сайт работает от одного файла — `data/Mesh_проверка_модели.xlsx` (путь в `config.json`, ключ `workbook`). Из него берутся тарифы, заказы и все расчёты. Служебные листы проверки модели («Замечания», «Соответствие ТЗ», «Стресс-тесты») сайт не читает и не показывает.

Книга перечитывается при каждом сохранении в Excel (≈3 с). Адреса ячеек модели читаются по позициям — не вставляйте строки и столбцы в листы модели.

## Код
На сайте кода нет. Все исходники — обычные текстовые файлы в папке проекта (см. «Структуру»); открывайте их в VS Code или Блокноте.

## API
`/api/data`, `/api/state`, `/api/analytics`, `/api/receive`, `/api/orders`, `/api/orders/{id}/{assemble|dispatch|deliver|return}`, `/api/time/advance`, `/api/expire`, `/api/reset`, `/api/health`.

## Правило Mesh и начисления
Mesh, если товар доступен на ПВЗ А, ПВЗ Б доступен, покупатель в том же городе, в рейсе ≥ минимума заказов и целевой SLA ≤ 6 ч; иначе — хаб. Все тарифы берутся из Excel-модели и являются сценарными допущениями команды.
