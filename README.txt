MESH DELIVERY — КАК ЗАПУСТИТЬ
=============================

1. Распакуйте архив в отдельную папку (не запускайте из архива).
2. Дважды щёлкните START.bat.
   - Первый раз: сам создаст папку .venv и поставит библиотеки (нужны Python 3.9+ и интернет, 1–2 минуты).
   - Дальше: запускается сразу, сайт откроется в браузере (http://127.0.0.1:8000).
3. Остановить: Ctrl+C или закройте чёрное окно.

Python нет? Скачайте с https://www.python.org/downloads/ и при установке отметьте «Add python.exe to PATH».
macOS / Linux: ./start.sh  (или python3 run.py).

EXCEL — ОДНА ТАБЛИЦА
- Весь сайт работает от одного файла: data/Mesh_проверка_модели.xlsx. Путь указан в config.json (ключ workbook).
- Листы проверки модели («Замечания», «Соответствие ТЗ», «Стресс-тесты») сайт не показывает.
- Правите в Excel, сохраняете — сайт обновляется за ≈3 с. Не вставляйте строки и столбцы в листы модели:
  ячейки читаются по адресам.

КОД (на сайте кода нет — только в файлах папки)
- Любой файл .py / .js / .css / .html / .json: правая кнопка -> «Открыть с помощью» -> Блокнот / VS Code
  (для .py ещё есть «Edit with IDLE»). Лучше поставить бесплатный VS Code и открыть папку целиком.
- static/app.js, style.css, index.html — интерфейс (сохранили, нажали F5);
  main.py, engine.py, excel_io.py — сервер и расчёты (после правки перезапустите START.bat);
  run.py — лаунчер; config.json — порт и путь к Excel.
